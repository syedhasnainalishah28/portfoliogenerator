## ⚡ How to Use

1. **Open any template:** Simply double-click `index.html` to open in browser
2. **Customize your name:** Search `Ctrl+F` for placeholder names (Alex Carter, Sarah Morgan, etc.)
3. **Change colors:** Edit Tailwind config at top of each file
4. **Add your projects:** Replace project cards with your real work
5. **Deploy:** Upload `index.html` directly to:
   - [Vercel](https://vercel.com) (drag & drop)
   - [Netlify](https://netlify.com) (drag & drop)
   - [GitHub Pages](https://pages.github.com)

## ✏️ Customization Guide

### Change Your Name
```html
<!-- Find and replace in index.html -->
"Alex Carter" → "Your Name"
```

### Change Profile Initials
```html
<!-- Find the initials placeholder -->
<div class="...">AC</div>
<!-- Change to your initials -->
<div class="...">YN</div>
```

### Add Real Profile Photo
```html
<!-- Replace the initials div with: -->
<img src="your-photo.jpg" class="w-full h-full object-cover rounded-full" alt="Your Name" />
```

### Change Color Theme (Template 1 Example)
```js
// In tailwind.config, change neon colors:
neon: {
  cyan: '#YOUR_COLOR',  // Primary accent
  green: '#YOUR_COLOR', // Secondary
  pink: '#YOUR_COLOR',  // Highlight
}
```
